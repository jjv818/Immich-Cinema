# Immich Cinema 6.2.0-cinema.1

A premium Android TV client for a personal Immich photo and video library. This is the first
standalone release: forked from [`giejay/Immich-Android-TV`](https://github.com/giejay/Immich-Android-TV)
6.2.0 (148) and rebuilt around a television-first interface.

Unofficial. Not affiliated with, endorsed by, or sponsored by the Immich project.

## Requirements

- Android TV / Google TV, Android 7.0 (API 24) or newer. Tested on a Sony BRAVIA (Android 12,
  1920?1080 @ 320dpi).
- An Immich server you can reach from the TV, and an API key for it.
- Sideload only for now: there is no Play Store listing.

## Install

```bash
adb connect <tv-ip>:5555
adb install -r ImmichCinema-6.2.0-cinema.1.apk
```

First run asks for your server and API key (or lets you try demo mode).

To use it as the screensaver as well:

```bash
adb shell settings put secure screensaver_components \
  com.immichcinema.tv/nl.giejay.android.tv.immich.screensaver.ScreenSaverService
```

The TV ignores that setting while the app is installed but not yet launched once ??open the app
before changing it.

## Known limitations

Documented in full in `docs/v2/UI_UX_VALIDATION_v2.md` 禮4.3. The ones a user can notice:

- The grid background cross-fade follows `BackgroundManager`'s cadence on some pages rather than the
  design's 250ms.
- Home-screen channel rows do not appear on Sony's launcher, which renders no third-party preview
  channels at all.
- The error state cannot be reproduced without cutting the network, so it is covered by tests rather
  than by a device screenshot.
